Panduan Upload ke GitHub Pages & Firebase Hosting

Opsi 1 — Uji Coba Cepat & Gratis via GitHub Pages (2 Menit)

  1. Simpan kode aplikasi ini ke komputer Anda dengan nama persis index.html (huruf kecil semua).
  2. Buka GitHub → klik New Repository → beri nama (contoh: KAN-Timesheet) → pastikan visibilitas Public → klik Create repository.
  3. Klik uploading an existing file → unggah index.html langsung di halaman paling luar (root, bukan di dalam folder) → klik Commit changes.
  4. Buka tab Settings → menu Pages → pada Build and deployment pilih Branch main dan folder / (root) → klik Save.
  5. Tunggu 1–2 menit hingga centang hijau muncul di tab Actions, lalu akses tautan https://username.github.io/KAN-Timesheet/.

Opsi 2 — Hosting Produksi via Firebase Hosting

  1. Pastikan Node.js sudah terpasang, lalu buat folder proyek (misal kan-timesheet) dan buat sub-folder public.
  2. Letakkan file index.html di dalam folder public/index.html.
  3. Buka terminal di dalam folder proyek, lalu jalankan perintah berikut secara berurutan:
npm install -g firebase-tools && firebase login && firebase init hosting && firebase deploy

Saat ditanya direktori publik oleh Firebase CLI, ketik public dan pilih No untuk overwrite index.html.
