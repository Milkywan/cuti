Panduan Upload Gratis ke GitHub Pages & Firebase Hosting

Aplikasi ini dibangun dalam 1 file mandiri (index.html) tanpa membutuhkan server backend. Ikuti langkah berikut untuk meng-online-kannya:

Langkah 1: Simpan File Sebagai index.html

Simpan seluruh kode aplikasi ini ke dalam folder baru di komputer (misal folder kan-timesheet) dengan nama file wajib: index.html.

Langkah 2: Ujicoba Cepat via GitHub Pages (Tanpa Terminal)

  1. Buka github.com → klik New Repository (beri nama kan-timesheet, pilih Public).
  2. Klik uploading an existing file → seret file index.html → klik Commit changes.
  3. Masuk ke tab Settings → Pages → di bagian Branch pilih main lalu klik Save. Link publik langsung aktif dalam ±1 menit!

Langkah 3: Deploy ke Firebase Hosting (Produksi)

Buat project di console.firebase.google.com, lalu jalankan perintah berikut di terminal dalam folder project (pilih folder publik . saat ditanya): 

npm install -g firebase-tools
firebase login
firebase init hosting
firebase deploy
