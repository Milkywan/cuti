Panduan Upload Gratis ke GitHub Pages & Firebase

Aplikasi ini dibangun dalam 1 file mandiri (index.html) tanpa membutuhkan server backend. Lo bisa langsung meng-online-kannya gratis dalam 3 menit:

Langkah 1: Simpan Kode Sebagai index.html

Download atau copy seluruh kode HTML aplikasi ini, simpan ke dalam folder baru di laptop lo (misal folder kan-timesheet) dengan nama file wajib: index.html.

Langkah 2: Ujicoba Cepat via GitHub Pages (Tanpa Terminal)

  1. Buka github.com → klik New Repository (beri nama misal kan-timesheet, pilih Public).
  2. Klik uploading an existing file → tarik file index.html → klik Commit changes.
  3. Masuk ke menu Settings → Pages → pada bagian Branch pilih main lalu klik Save. Link web langsung aktif dalam ±1 menit!

Langkah 3: Deploy ke Firebase Hosting (Opsional / Produksi)

Buat project di console.firebase.google.com, lalu jalankan perintah berikut di terminal dalam folder project lo (pilih folder publik . saat ditanya): 

npm install -g firebase-tools
firebase login
firebase init hosting
firebase deploy
